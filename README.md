# Đồ án: Website Chia sẻ Công thức Nấu ăn

## 1. Giới thiệu dự án
Repository quản lý mã nguồn đồ án môn học Chuyên đề ASP.NET. Nền tảng trực tuyến cho phép người dùng tra cứu, lưu trữ và chia sẻ các công thức ẩm thực cá nhân.
*   **Công nghệ:** ASP.NET Web Forms (C#), HTML5, CSS3, Bootstrap.
*   **Cơ sở dữ liệu:** Microsoft SQL Server.
*   **Kiến trúc:** Mô hình 3 lớp (3-Tier Architecture).

## 2. Hướng dẫn cài đặt
1. Mở SQL Server Management Studio (SSMS), chạy file `QLCongThucNauAn.sql` trong thư mục `setup` để tạo CSDL và dữ liệu mẫu.
2. Mở thư mục `src` bằng Visual Studio.
3. Mở file `Web.config`, chỉnh sửa chuỗi kết nối (`connectionStrings`) cho khớp với Server Name trên máy của bạn.
4. Nhấn `F5` hoặc `IIS Express` để chạy ứng dụng.
